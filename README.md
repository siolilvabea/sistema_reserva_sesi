# Reserva SESI

## Sobre o Projeto
O **Reserva SESI** é um sistema web desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Desenvolvimento de Sistemas do SENAI. 

O objetivo principal é centralizar as informações sobre as salas e laboratórios da escola SESI Milton Sobrosa Cordeiro, facilitando o controle, a organização e o processo de agendamento dos espaços educacionais, substituindo o uso de ferramentas generalistas e evitando conflitos de horários.

## Funcionalidades
* **Visualização de Espaços:** Catálogo completo de todas as salas, laboratórios e espaços disponíveis.
* **Consulta de Disponibilidade:** Filtros por data e horário para verificar a ocupação em tempo real.
* **Gestão de Reservas:** Criação, alteração e cancelamento de agendamentos de forma simples.
* **Histórico de Agendamentos:** Painel para o usuário consultar suas reservas anteriores e ativas.
* **Controle de Limpeza:** Sistema de bloqueio automático de horários destinados à manutenção e limpeza dos espaços.

## Tecnologias Utilizadas
O projeto está sendo desenvolvido no modelo Web, focado no Front-end com as seguintes tecnologias:
* **HTML5**
* **CSS3**
* **JavaScript (JS)**
